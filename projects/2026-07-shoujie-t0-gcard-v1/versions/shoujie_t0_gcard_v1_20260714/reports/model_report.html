4 选型理由

moderate_reg 在所有候选模型中实现最优的 KS gap 控制（DEV_INS 与 OOT 的 KS 差异 = 2.51pp，满足 ≤ 3pp 要求），同时保持了良好的区分度（OOT AUC=0.7545, OOT KS=0.3716）。shallower 虽然有更低的 KS gap（1.42pp），但其 OOT KS（0.3632）和 OOT AUC（0.6816）明显偏低，区分度不足。

3 结论

新模型在全部分析口径上均显著优于旧版 v1_score：

  • OOT KS 提升 20.2%（0.3104 → 0.3731），区分度大幅改进
  • OOT AUC 提升 5.68%（0.7145 → 0.7550）
  • 过拟合控制良好：KS gap 2.51pp，AUC gap 1.79pp
  • 分数单调性和排序一致性均满足上线标准
