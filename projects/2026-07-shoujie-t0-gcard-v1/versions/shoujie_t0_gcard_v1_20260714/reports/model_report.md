## 13. 结论和建议

### 13.1 模型总结

| 维度 | 结论 |
| --- | --- |
| 区分度 | OOT AUC=0.7497, KS=0.3650，显著优于 v1_score（OOT KS +17.6%） |
| 稳定性 | 全部月份 PSI < 0.11，分数分布稳定 |
| 过拟合 | KS gap (DEV_INS−OOT) = 0.0191 ≤ 3pp ✓ |
| 排序性 | OOT 十分位 lift = 4.83x，单调递减 |
| 额度一致性 | 额度与风险排序一致（高额度→高风险→低分） |

### 13.2 建议行动

1. **建议灰度上线** — moderate_reg OOT 表现显著优于 v1_score，KS 相对提升 17.6%，且过拟合控制达标
2. **积累 OOT** — 当前仅 2 个月外推窗口（2026-04 ~ 2026-05），建议积累 4-6 个月后回测
3. **补充 MOB 和金额风险分析** — 后续版本补齐
4. **建立模型监控** — 部署后监控 PSI、KS/AUC 衰减、分客群效果
5. **引入 A 卡分** — 补充 A×G 交叉矩阵，完善风险分层

### 13.3 使用限制

- 适用于首借 T0 G 卡客群
- 不含 A 卡分（a_card_score 不存在于样本）
- 重审客群 OOT 仅 1 条样本，分客群评估不适用
- OOT 仅 2 个月，代表性和稳健性待更多数据验证
- MOB 分析、金额风险矩阵待后续版本补充
- v1_score 含 88,811 空值，对比仅对有效样本进行
